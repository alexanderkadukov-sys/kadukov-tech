Данные личного кабинета

На сайте КАДУКОВ можно искать запчасти, смотреть услуги и обращаться к мастеру. Кабинет нужен для входа под своим аккаунтом.

Какие данные используются

  • При входе через Google сервис входа получает идентификатор аккаунта, адрес электронной почты и данные базового профиля, включая имя и фото, если они доступны. Эти данные используются для создания кабинета, распознавания пользователя при повторном входе и показа данных аккаунта. Сайт не запрашивает доступ к Gmail, Google Диску или контактам.
  • При входе через Telegram сервис входа получает идентификатор и базовые данные профиля. Сайт использует их для создания кабинета и распознавания пользователя при повторном входе. Номер телефона и доступ к переписке для входа не запрашиваются.
  • При входе по почте используется адрес, который вы вводите для получения письма.
  • Ключ входа подтверждается на вашем устройстве. Сайт не получает отпечаток, изображение лица и PIN-код. Для проверки ключа сервис входа хранит его открытую часть.

Где хранятся данные

Supabase обрабатывает данные для входа и хранит запись кабинета и привязанные способы входа. Google и Telegram обрабатывают вход через свои сервисы. В текущей вкладке браузер сохраняет данные сеанса, чтобы кабинет оставался открытым после обновления. Через кнопку «Выйти» можно завершить сеанс.

Сайт использует данные аккаунта Google для входа и работы кабинета. Эти данные не используются для рекламы и не продаются.

Как обратиться по поводу данных

За доступом к данным кабинета, их исправлением или удалением обратитесь к Александру Кадукову по адресу alexanderkadukov@gmail.com. Укажите способ входа и адрес аккаунта, если он есть. Пароли, коды и ключи указывать не нужно.
