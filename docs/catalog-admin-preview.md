# V4.0.1 — catalog admin preview

Open /admin/ on the GitHub Pages demo. This is a browser-only test editor, NOT a secured admin system. No server connection, no login and no storefront sync. The main site is unchanged. Local data is stored by this origin in localStorage; export before clearing browser data. Only test product data, no personal information or credentials. Import replaces the local list after validation and confirmation; export is JSON. SKU uniqueness is case-insensitive. Prices are integer RUB or null (on request).

Database draft: docs/catalog-schema-draft.sql. Do not run against DomFar3D or any unrelated project. Provision a dedicated test project only after organization, region and cost approval. Review current Supabase docs and security advisors before applying. The draft intentionally contains no customer records, supplier purchase prices or real keys. Public reads only published products; admin writes and draft access require server-managed app_metadata plus aal2. Test anon, authenticated non-admin, admin aal1 and admin aal2; verify explicit grants, RLS, denied writes, uniqueness, and backup/restore before enabling frontend. Use a private backend for supplier costs, audit logs, orders and customer data. Never put service-role keys in client or public GitHub. Commercial launch requires suitable hosting and data-location review.

Next: create separate test DB, set up real auth/MFA, connect admin with publishable key and RLS, add image storage, stage/import verified products, connect read-only storefront, test in browser and deploy production separately.
