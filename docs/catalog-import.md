# V4.0.4 — atomic catalog import
CSV UTF-8 (semicolon, comma or tab), XLSX first sheet via isolated worker (SheetJS CE 0.20.3, official pinned CDN). Template required; max 5 MB and 500 nonblank rows. No formula evaluation. Excel SKUs must be text. New products are drafts, existing SKUs skipped by default, optional price-only updates require explicit preview/confirmation. Price blank never overwrites an existing price. No photo, description, stock or publication changes for existing products. DB uses catalog_import_lookup(text[]) and catalog_apply_import(jsonb), both SECURITY INVOKER, grants authenticated only and app_metadata admin + AAL2. RLS enforced. Unique SKU index and updated_at optimistic lock reject conflicting writes; one RPC transaction. Test insert, price update, duplicate rollback, AAL1 denial with rolled-back transaction. No production import performed. Browser XLSX/CDN and real administrator import must still be verified. Vendor dependency locally with lockfile/integrity before production.
