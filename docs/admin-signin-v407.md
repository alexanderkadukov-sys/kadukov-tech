# V4.0.7 — administrator sign-in options
Existing role and AAL2 checks, database/storage policies, product editor, images and imports remain unchanged. New sign-in options: password, passkey, Google OAuth (PKCE), email OTP (existing accounts only). Optional tab session: custom memory/sessionStorage adapter, 8h local restore window; not a server-side session expiry or a trusted-device biometric lock. No persistence in localStorage, no stored passwords. AAL2 remains required regardless of first sign-in method; Passkey may still require TOTP. Passkey API experimental, explicit opt-in. Registration/list/removal UI only after AAL2; keep TOTP backup.
