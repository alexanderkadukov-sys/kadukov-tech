# V4.0.3 — private product images
Existing catalog data and storefront preserved. After saving a product or editing an existing item, use Photos. Five fixed slots (<product UUID>/1.jpg … 5.jpg), lowest existing slot is cover. JPEG/PNG/WebP up to 15 MB source; browser encodes JPEG up to 1600px and 2 MiB. Private bucket, only admin AAL2 read/write/delete; no UPDATE policy, no overwrites. File operations via Storage API, not SQL. Partial uploads are reported and list refreshed. Images are separate from product edits, not yet public. Before deleting a product in future, remove its photos via Storage API; this UI has no product hard delete. No customer files.
Test with a real admin browser before claiming end-to-end upload; verify actual objects in Storage, download and removal. Do not upload sensitive photos.
